# Fidus — site

Site estático do [Fidus](https://github.com/tiagoluizrs/fidus), publicado em **https://fidus.pythondeaaz.com.br** pelo GitHub Pages.

- `index.html`: o que é o Fidus
- `politica.html`: Política de Privacidade
- `termos.html`: Termos de Uso
- `CNAME`: domínio do Pages (`fidus.pythondeaaz.com.br`)

Sem build: é só HTML e CSS. Para publicar: Settings > Pages > *Deploy from a branch* > `main` / `(root)`.
No DNS do domínio `pythondeaaz.com.br`, crie um registro **CNAME** `fidus` apontando para `tiagoluizrs.github.io`.
